# User Personas & User Journeys

**Project:** Progress Tracker PWA
**Version:** 1.0

## 1. Target Users

**Primary Users**
- Students
- Software Engineers
- Freelancers
- Startup Founders
- Competitive Exam Aspirants
- Remote Workers

**Secondary Users**
- Designers
- Researchers
- Content Creators
- Self-learners

## Persona 1 — Student

**Profile**
- Age: 18–24
- Occupation: College Student
- Goals: Complete assignments, prepare for exams, build projects.
- Pain Points:
  - Easily distracted.
  - Doesn't plan consistently.
  - Misses deadlines.
  - Doesn't know how productive the day was.

**Needs**
- Structured daily planning.
- Study reminders.
- Progress tracking.
- Weekly academic goals.

**Success Criteria**
- Completes planned study sessions.
- Maintains study consistency.

## Persona 2 — Software Engineer

**Profile**
- Age: 22–35
- Occupation: Developer
- Goals: Finish sprint tasks, learn new technologies, maintain work-life balance.
- Pain Points:
  - Context switching.
  - Long task lists.
  - Forgetting planned work.
  - No reflection after work.

**Needs**
- Session-wise work tracking.
- Daily planning.
- Weekly sprint goals.
- Productivity reports.

**Success Criteria**
- Finishes planned work.
- Maintains weekly progress.

## Persona 3 — Freelancer

**Profile**
- Age: 20–40
- Occupation: Freelancer
- Goals: Deliver projects on time while balancing multiple clients.
- Pain Points:
  - Client work overlaps.
  - Poor time management.
  - Missed follow-ups.
  - Difficulty measuring progress.

**Needs**
- Session planning.
- High-priority task tracking.
- Daily accountability.
- Weekly progress review.

**Success Criteria**
- Meets client deadlines.
- Improves daily execution.

## Persona 4 — Startup Founder

**Profile**
- Age: 22–40
- Occupation: Founder
- Goals: Build product consistently while managing multiple responsibilities.
- Pain Points:
  - Constant interruptions.
  - Too many priorities.
  - No structured execution.
  - Loses focus.

**Needs**
- Daily execution plan.
- Weekly company goals.
- Continuous reminders.
- Progress visualization.

**Success Criteria**
- Executes high-impact work consistently.

## Persona 5 — Competitive Exam Aspirant

**Profile**
- Age: 18–30
- Occupation: Exam Candidate
- Goals: Follow study schedule and complete syllabus.
- Pain Points:
  - Skips study sessions.
  - Inconsistent routine.
  - Doesn't review progress.

**Needs**
- Daily study planning.
- Revision reminders.
- Weekly syllabus tracking.
- Achievement visualization.

**Success Criteria**
- Maintains study streak.
- Completes weekly targets.

## Primary User Actions

- Sign up / Log in
- Create weekly goals
- Plan tomorrow
- Add session tasks
- Receive reminders
- Update progress
- Complete tasks
- Skip or move tasks
- View dashboard
- Browse calendar
- Review daily report
- Review weekly report

## User Expectations

- Know what to do next without confusion.
- Receive timely reminders.
- Update progress in under one minute.
- See meaningful progress instantly.
- Feel motivated after completing work.
- Easily review past performance.

## Pain Point → Solution Mapping

| Pain Point | Product Solution |
|---|---|
| Forgetting tasks | Time-based reminders |
| No planning habit | Night planning workflow |
| Losing focus | Session-based execution |
| No accountability | Mandatory progress check-ins |
| No visibility | Dashboard & calendar |
| No long-term tracking | Weekly goals |
| Low motivation | Gamification |
| No reflection | Daily & weekly reports |

## Key Experience Principles

1. **Plan Once** – Create tomorrow's plan before sleeping.
2. **Execute in Sessions** – Focus on one session at a time.
3. **Track Continuously** – Record progress after every reminder.
4. **Reflect Daily** – End each day with achievements and pending work.
5. **Improve Weekly** – Measure progress against weekly goals.
6. **Stay Motivated** – Reinforce consistency through gamified feedback.

## Gap Identified Before Design

One critical persona is still missing: the **Habit Builder** — a user whose primary objective is building routines (e.g., exercise, reading, meditation) rather than completing project-based tasks. If the app aims to become a general productivity platform, this persona should be considered in future versions; otherwise, the current personas align well with the defined product vision.
