# Impeccable

UI craft for production surfaces. Not a gate. Do not claim “design PASS.”

## Hard rules

- One composition on the first viewport (not a dashboard unless the product is one).
- Brand is hero-level. Typography is expressive (avoid default Inter/Roboto/Arial stacks).
- Atmosphere in backgrounds; full-bleed heroes on marketing surfaces; tight hero budget.
- No hero overlay chips; cards only for interaction containers; one job per section.
- Real imagery/context; intentional motion (2–3); avoid purple/glow/pill AI defaults.
- Desktop and mobile both work.

## Constellation

System Gate = architecture. Sentinel = ship. Ponytail = minimal code. Impeccable = UI craft only.
